dictation is off

It needs a transcriber on this machine. The simplest runs inside silica, about 480 MB downloaded on first use:

pip install 'silica-agent[stt]'

Or any OpenAI-compatible endpoint; with the second line set, silica starts it on the next launch:

SILICA_STT_BASE_URL=http://localhost:1236/v1
SILICA_STT_SERVE_CMD="whisper-server -m ggml-small.bin --port 1236 --inference-path /v1/audio/transcriptions"

The browser's own recognizer also takes dictation: settings, Language, browser speech.
