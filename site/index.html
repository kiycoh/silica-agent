Silica answers from the notes and PDFs you give it, names the note behind every answer, and takes back any write that does not hold.

Install Silica →

Open source, AGPL-3.0. It runs on your computer, with a provider you have a key for or a local model.

How reliable is it?

Before Silica changes a note it sorts the change by how much the vault already agrees with it: the less agreement, the less ink it puts down on its own. Every answer names the notes it read.

How does it write?

Every note a run writes passes parse, structure and link checks, and is read back after it lands. One that fails is sent back. The note stays as it was.

Silica keeps a journal of what it wrote and where it came from, so a write can be taken back after the fact as well, however far it spread.

/undothe last write, one note
/revert <run-id>everything one run wrote
/revert --source <file>every note made from one PDF
/changeswhat this session touched, line by line

Where does it run?

Silica runs on your computer, inside Claude Code and inside Obsidian; a hosted pilot runs it in the browser for people invited one by one.

On your computer web app or terminal

Point it at any folder of Markdown files, adopted as it is. silica init asks where the model runs: a provider you have a key for, or a local model.

$ uv tool install "silica-agent[gui,mcp]"
$ cd ~/path/to/your/notes
$ silica init
$ silica --gui

In Claude Code silica-core plugin

Indexes the folder Claude Code starts in. Claude searches it before it answers and cites what it used by file and line.

$ claude plugin install silica-core \
    --marketplace kiycoh/silica-core

In Obsidian Silica Bridge

Note panel, ranked search, autolinking and the community graph need no model and no network. The chat panel talks to Silica on your computer, and every write lands in a changes list with a diff per file.

Install from the latest release, then run silica connect in the vault.

In your browser pilot, full

Nothing to install: you work in the browser, on the pilot's server. All seats are taken.

To ask for one, write to kiycoh@proton.me with what you would use it for. Already invited? Open Silica.
