# silica-harness has been renamed to silica-agent

This package exists only to redirect. Installing it installs
[`silica-agent`](https://pypi.org/project/silica-agent/), which is where
the project now lives, and the `silica` command keeps working.

Install the new name directly:

```
uv tool install silica-agent      # or: pipx install silica-agent
```

Source, issues and documentation: https://github.com/kiycoh/silica-agent
